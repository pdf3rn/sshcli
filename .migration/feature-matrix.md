- Deterministic evidence: VT tests 5 passed; terminal-ui 9 passed; local PTY 8 passed; SSH connection-error test passed; SSH lifecycle fixture failed (23 passed, 1 failed across focused checks).
- Quality gate: selected-package `cargo fmt --check` failed, including formatting differences in `crates/gui/src/native_terminal.rs`; build checks passed. `slint-viewer` is unavailable.
