# sshcli feature parity checklist

Inventory and verify as applicable:

## Connections
- saved profiles
- quick connect `user@host[:port]`
- groups
- tags
- favorites
- authentication/key options
- reconnect
- host-key behavior
- errors/status

## Terminal
- remote terminal
- local PTY
- resize
- tabs
- splits
- shortcuts
- selection/clipboard
- scrollback
- font/theme
- high-volume output

## SFTP
- navigation
- upload/download
- progress
- cancellation
- overwrite behavior
- errors
- refresh
- drag/drop if present

## Tunnels
- local forwarding
- remote forwarding
- dynamic/SOCKS if present
- start/stop/status
- error handling
- persistence

## Desktop
- menus
- tray if present
- notifications
- window persistence
- startup behavior
- settings
- platform-specific behavior
